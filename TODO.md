- [ ] s-finite measure monad for the continuous model (`StatisticalInterface` over `QBSCat cantorSource`). Hardest. Literature (Staton 2017; Hirata–Minamide–Sato ITP 2023; Affeldt–Cohen–Saito CPP 2023) gets these from a host measure-theory library.
